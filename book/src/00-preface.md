# Nginx 纵深加固：从反向代理到 WAF 实战

> 把 Nginx 当成一座"互联网城门"——它既是性能最快的反向代理，也是攻击者最爱的隐身舞台。

## 为什么写这本书

在 2026 年写一本关于 Nginx 的书，听起来有点"过时"——Nginx 2004 年就发布了，21 年历史，网络上有不计其数的教程。但在 SRE 和安全工程师的组织中，80% 的 Nginx 仍配置错误。不是他们不想正确——市面上缺的是"纵深"视角的书。

这本书不是 Nginx 入门教程。它假设您已经知道 Nginx 怎么运行、怎么配 location、怎么配 proxy_pass。它要做的是：**把 Nginx 当成攻防双方的主战场**，告诉您攻击者会怎么用 Nginx 摸配置、找路径、绕认证、提权、隐攻击，然后交给您一套五层纵深防御体系来守住每一道门。

## 这本书适合谁

- **SRE / 运维工程师**：负责 Nginx 在生产环境的部署、调优、应急
- **后端 / 全栈开发者**：用 Nginx 做反向代理，但不清楚如何安全配置
- **安全工程师**：需要对 Nginx 配置做合规审计、风险评估
- **架构师**：在做 API 网关 / CDN / 微服务网关的技术选型
